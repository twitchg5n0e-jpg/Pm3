Kamera einrichten

Einmalig nötig: Das Handy muss dem Raspberry Pi vertrauen, sonst gibt der Browser die Kamera nicht frei.

1. Zertifikat herunterladen

iPhone (Safari)

  1. Oben auf den Knopf tippen → Erlauben.
  2. Einstellungen → Profil geladen → Installieren (Code eingeben).
  3. Einstellungen → Allgemein → Info → ganz unten Zertifikatsvertrauenseinstellungen → „Handy-Kamera CA“ einschalten.

Android (Chrome)

  1. Oben auf den Knopf tippen, die Datei wird gespeichert.
  2. Einstellungen → Sicherheit → (Weitere Einstellungen →) Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat → „kamera-ca.crt“ wählen.
  3. Android verlangt dafür eine Bildschirmsperre (PIN oder Muster).
